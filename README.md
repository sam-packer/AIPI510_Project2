# AIPI 510 Project 2

This project has all the scripts, Jupyter notebooks, and CSV data for our statistical project in AIPI 510. Under the
scripts folder, you should run the scripts in order to understand our thinking.

### Power analysis script

This script will run a power analysis on how many cookies we need to bake. Since no one has done such an experiment
prior, we use a pilot sample. We initially calculated we had to bake 34 pairs of cookies to prove any statistical
significance.
